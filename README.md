# Data Report Bot

## Описание
Telegram бот для автоматизации отчетности из Google Sheets. Бот предоставляет ежедневный отчет о состоянии проектов: статистику выдачи данных, остатки тарифов и предупреждения о необходимости отключения или уменьшения лимитов.

## Основные функции
📊 **Дополнительный отчет**
   - Автоматическая отправка в 13:40 МСК
   - Ручная отправка по команде `/secondary` или кнопке "📊 Доп. отчет"
   - Показывает для каждого активного проекта:
     - Общий объем тарифа
     - Выдано итого
     - Выдано за сегодня
     - Остаток тарифа
   - Предупреждения:
     - 🚨 Проекты с исчерпанными тарифами (нуждаются в отключении)
     - ⚠️ Проекты с остатком меньше чем на день (нуждают в уменьшении лимитов)

## Установка

### 1. Подготовка
- Установите Python 3.9 или выше
- Скачайте код проекта

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Создайте файл `.env` в корне проекта:
```
BOT_TOKEN=ваш_токен_бота
ADMIN_CHAT_ID=ваш_id
GROUP_CHAT_ID=id_группы
SECONDARY_SPREADSHEET_ID=id_таблицы
CREDENTIALS_FILE=путь_к_credentials.json
```

### 4. Настройка Google Sheets
1. Создайте проект в Google Cloud Console
2. Включите Google Sheets API
3. Создайте Service Account
4. Скачайте credentials.json
5. Поместите файл в папку credentials/

## Использование

### Запуск бота

```bash
python main.py
```

### Команды бота
1. `/start` - Открыть главное меню
2. `/secondary` - Дополнительный отчет по второй таблице
3. `/test` - Тестовая команда (отправляет сообщение в группу)

### Автоматические отчеты
- Отправляются ежедневно в 13:40 МСК
- Приходят в групповой чат

## Обслуживание

### Проверка работоспособности
1. Бот отвечает на команду `/start`
2. Автоотчеты приходят в 13:40 МСК
3. Данные из второй таблицы актуальны

### Решение проблем
1. **Бот не отвечает**
   - Проверьте запущен ли скрипт
   - Проверьте токен бота

2. **Нет доступа к таблице**
   - Проверьте credentials.json
   - Проверьте права доступа

3. **Отчеты не приходят в группу**
   - Проверьте ID группы
   - Проверьте права бота в группе
